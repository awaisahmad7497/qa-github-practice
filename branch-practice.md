
# Git Branch Practice

## Purpose
Practice using feature branches and pull requests for QA work.

## Example QA Workflow
1. Identify a defect or testing improvement.
2. Create a feature branch.
3. Make and review the changes.
4. Commit the changes.
5. Push the branch to GitHub.
6. Open a pull request.
7. Review and merge the changes.

## SQA Principle
Keep changes small, understandable, and easy to review.
